# CAULBORN (working title)

A darker-fantasy 2D pixel-art RPG in the spirit of Undertale: bullet-hell encounters that characterize their casters, a morality system where killing and *consuming* are separate sins, and a magic system drawn from the pain of the imprisoned being the world was built around.

- **Design bible:** [design/](design/) — start with [design/00-vision.md](design/00-vision.md). Canon ledger: [design/CONTINUITY.md](design/CONTINUITY.md) (*not in the ledger = not canon*).
- **Implementation plan:** [design/06-implementation-plan.md](design/06-implementation-plan.md)
- **Engine:** Godot 4.x, standard build (GDScript). Open in Godot via *Import* → select `project.godot`, then run (F5).
- **Current target:** Chapter 1 vertical slice (The Fallows), Bell's encounter first.
